# AgendaCasal

A shared agenda / private space for couples — calendar, reminders, chat, and voice notes in one place, built as a mobile-first PWA.

Two people pair up with an invite code and get a shared dashboard: a calendar for events, a reminders list, a lightweight chat, and voice-note recording — plus push notifications so nothing gets missed.

## Features

- Pair with a partner via invite code (no public sign-up list, just the two of you)
- Shared calendar for events
- Reminders list
- Built-in chat
- Voice-note recording
- Web push notifications
- Installable PWA with offline-friendly caching

## Tech stack

Next.js 14, React, TypeScript, Tailwind CSS, Supabase, Firebase, Web Push API, PWA (service worker)
